# FOLD 01

A standalone interactive furniture design study. The page unfolds a continuous sculptural chair into its upholstery, shell and tubular frame, then brings it back together for configuration.

## Run and publish

Use any static HTTP server. No build, package installation, backend, remote fonts or external asset fetch is needed. Direct file opening can block module imports in browsers, so HTTP is recommended.

For GitHub Pages, place this folder at a repository root and publish it. All paths are relative and .nojekyll is included.

## Controls

- Native scrolling reversibly opens the material layers and changes the camera framing.
- Mouse dragging rotates the same fully modeled chair. Reset restores the chosen angle. A Turn 45° button provides the equivalent deliberate action on narrow screens.
- Four colour swatches immediately update upholstery, shell and piping.
- Bouclé and Soft touch change surface roughness and bump detail.
- The object and Save your Fold open a real accessible dialog. Download specification creates a local text file with the exact chosen colour and material.

Reduced motion uses discrete chapter compositions. If WebGL fails, a local SVG provides a static chair preview, and the configuration, specification and download remain usable.

## Scope

FOLD 01 is a design concept, not a real product in production. Its dimensions are design study values. There is no checkout, reservation, real order or payment flow.

See DESIGN.md for the scene map and assets/LICENSES.md for dependency provenance. Physical-device and browser observations must be distinguished from source inspection.

The mobile experience now reserves explicit photographic or live-model frames in normal document flow. It does not move the hero object into arbitrary gaps between text blocks. Header, content, forms and footer share the mobile reading grid; desktop retains its cinematic composition. Exact local static font weights avoid variable-default differences across browser engines.
